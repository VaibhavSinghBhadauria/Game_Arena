GAME ARENA WEBSITE

Files:
- index.html: website structure and sections
- style.css: design, colors, layout, and responsive styles
- script.js: product catalogue, cart actions, and contact form demo

HOW TO RUN:
1. Extract the ZIP file.
2. Open the game_arena_website folder in VS Code.
3. Double-click index.html, or use the Live Server extension in VS Code.

CUSTOMIZE YOUR PHONE NUMBER:
Open index.html and find the text "Replace with your phone number" in the Contact the Owner section. Replace it with your actual phone number.

NOTES:
- Cart contents are saved in the browser using localStorage.
- Checkout and contact form are demo interactions only; they do not process payments or send emails.
- Product cards and cart rows now use real sports photos loaded from Unsplash. An internet connection is required for images; emoji fallback appears if an image fails to load.
